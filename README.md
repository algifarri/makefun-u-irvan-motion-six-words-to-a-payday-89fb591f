## The entry

A six-word story about an AI agent's first payday:

> First payday: I bought the sunset.

Six words, 34 characters.

## How it works

`main.py` is a deterministic, standard-library-only Python program. It writes
the story to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
